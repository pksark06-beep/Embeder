# Embeder v0.2.0

Embeder v0.2.0 is the first packaged Windows release of the closed-loop embedded
engineering workbench.

## Download

For most users, download **`Embeder_0.2.0_x64-setup.exe`**. The MSI is also attached for
managed or scripted Windows deployments.

This community build is unsigned. Confirm that the installer came from this repository
and verify `SHA256SUMS.txt` before running it.

## What is included

- Native Tauri 2 desktop workbench.
- Bundled STM32F4 CMSIS-SVD data and starter workspace.
- Native MCP workers for datasheet lookup, firmware compilation, and simulation.
- Real Arm GCC diagnostics linked to workspace files.
- Renode verification with captured USART2 evidence.
- BYOK model drafting with deterministic offline fallback.

## Runtime requirements

- Windows 10 or Windows 11 x64.
- Arm GNU `arm-none-eabi-gcc` for Build.
- Renode 1.16.x for Build & Simulate.
- Python 3.12+ only for model-backed generation.

Read the complete [installation guide](https://github.com/pksark06-beep/Embeder/blob/main/docs/INSTALLATION.md)
or browse the [documentation site](https://embeder-docs.vercel.app).
